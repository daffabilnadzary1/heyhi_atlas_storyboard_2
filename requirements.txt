# use `X | None` annotations that pydantic resolves at class-creation time, which
# is a TypeError on 3.9/3.10. macOS system Python will not run this.
#
# DERIVED FROM IMPORTS. The lower bounds below are the minimum the code needs;
# upper bounds are absent on purpose, because a bound nobody has tested is just a
# guess that ages badly.
#
# For the versions that are known to work, see requirements.lock.txt — a full
# snapshot of the environment the pipeline has been run end to end in, taken
# 2026-08-02. Install from THIS file; reach for the lock when an upgrade breaks
# something and you need a working set to compare against. Three surfaces are
# explicitly version-sensitive and will break silently on an upgrade — see the
# notes at the bottom.
